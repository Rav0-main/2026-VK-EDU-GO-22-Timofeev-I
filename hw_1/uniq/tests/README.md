# Тесты программы uniq.

## Примечание
Эти тесты имеют интеграционный характер, чтобы проверить, что программа целиком полностью работает.

## Запуск
Запустите bash скрипт:
```bash
./run.sh
```

## Ограничения тестирующей системы
Система не способна проверять результаты работы такие, у которых выход перенаправлен в отдельный файл, то есть в аргументах есть `output_file`.

## Структура
Файлы в `./data/` имеют два типа: `pos_[0-9]...` и `neg_[0-9]...`. Префикс `pos` обозначает, что результат работы `uniq` должен быть успешным (с кодом возврата `0`). Префикс `neg` обозначает, что результат работы должен завершиться с ненулевым кодом возврата.\
Суффиксы:
* `_in` - входные данные, которые будут получены программой через `stdin`
* `_out` - ожидаемые выходные данные, которые должны вывестись в `stdout` (ответ)
* `_args` - аргументы командной строки.
